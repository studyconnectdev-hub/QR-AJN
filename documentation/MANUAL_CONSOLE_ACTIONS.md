# Manual Console Actions That Cannot Be Safely Automated

- Create/own the Firebase project
- Accept Firebase/Google terms
- Enable Authentication providers
- Register Play Integrity/App Check release certificate
- Create AdMob app and ad units
- Configure consent/privacy messages
- Create and activate Play subscription products/base plans
- Grant Play Android Publisher API access to the backend service account
- Add qrajn.online DNS records at the domain registrar
- Complete GitHub authentication
- Submit Data Safety, ads declaration, content rating and store listing in Play Console
- Keep upload keystore and recovery password private
